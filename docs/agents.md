# Make a video with an agent

This is the main way to use manimvox: a coding agent (Claude Code, Codex, Cursor, Gemini CLI and others) makes the video through manimvox's skills, or an agent you build with a Python framework calls its tools. [How it works](how-it-works.md) explains what the agent does.
