# Made by your agent (about 100 seconds)

Question: What if you could ask your coding agent for an explainer video, and get one, with every claim cited?

## Opening
- What if you could ask your coding agent for an explainer video, and get one, with every claim cited?

## 1 What manimvox is  (picture: three cards, picture, voice, checks; then four workflow chips)
- manimvox is an open-source library and command line for narrated, animated explainer videos.
- Manim draws the picture, a voice tells the story, and checks catch mistakes before a video ships.
- It is built for AI agents: eleven skills teach an agent to make a video from a paper, an idea, a codebase or a pull request.

## 2 Why code, not tools  (picture: the question, then three cited cards, then "video = code")
- Why give an agent a library, and not a list of tools?
- Anthropic's engineers write that language models are adept at writing code.
- Cloudflare found that models are better at writing code that calls tools than at calling the tools directly.
- And the CodeAct study found that agents acting through Python code succeed up to twenty percent more often.
- So every manimvox video is code: code the agent writes, checks and fixes.

## 3 How to use it  (picture: a terminal with two commands, a prompt, the workflow, the heart video)
- Install manimvox, then give your coding agent its skills.
- Then just ask, for example: make an explainer video of the human heart.
- The agent gathers sources and writes down the facts, then the script.
- It writes the episode as Python, drafts it, reads its own checks, and renders.
- This heart video was made exactly that way, from three prompts.

## Ending
- Recap: built for agents; video as code; sources, script, checks.
- Answer: Ask your agent. It writes the video as code, cites every claim, and checks its own work.
