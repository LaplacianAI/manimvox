## What the parts do

- [SOURCE] Firefox shows a security indicator at the left end of the address bar, to the left of the web address; in recent versions it is a shield, in older ones a padlock. — https://support.mozilla.org/en-US/kb/how-do-i-tell-if-my-connection-is-secure
- [SOURCE] A plain padlock (or a shield with a check mark) means the connection between Firefox and the site is encrypted; a padlock with a red strike means the site uses the insecure HTTP protocol. — same article
- [SOURCE] In a URL, the part after `://` names the web server being requested, usually as a domain name (for example `developer.mozilla.org`); the first part, the scheme, such as https, says which protocol the browser must use. — https://developer.mozilla.org/en-US/docs/Learn_web_development/Howto/Web_mechanics/What_is_a_URL
- [EXTERNAL] The tab title is the page's own `<title>`, set by the page's author, so a page can call itself anything. — https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/title
- [EXTERNAL] The address bar is part of the browser's own interface, outside the page; a page's code does not draw it. (General browser design, stated for browsers in general, not as a guarantee about any one.)

## What the video does not claim

- That a site with the shield is trustworthy: the shield says the connection is encrypted, no more. The voice says "encrypted", never "safe".
