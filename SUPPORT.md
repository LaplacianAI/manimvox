# Getting help

- **Documentation:** [laplacianai.github.io/manimvox](https://laplacianai.github.io/manimvox/) covers installing, making a video with an agent or by hand, voices, blocks, 3D, configuration and the Python API.
- **Something isn't working:** run `manimvox doctor` first. It checks the system libraries, fonts and voice engines, and names the command that fixes anything missing.
- **A bug:** [open a bug report](https://github.com/LaplacianAI/manimvox/issues/new?template=bug_report.yml) with the output of `manimvox doctor` and the smallest episode that shows the problem.
- **An idea or a missing feature:** [open a feature request](https://github.com/LaplacianAI/manimvox/issues/new?template=feature_request.yml), or see what is planned in the [roadmap](https://github.com/LaplacianAI/manimvox/blob/main/ROADMAP.md).
- **A security problem:** report it privately, as [SECURITY.md](https://github.com/LaplacianAI/manimvox/blob/main/SECURITY.md) describes.

manimvox is maintained by volunteers, so answers can take a few days.
